# Project instructions

## Planning & documents

- Never write plans or specs to `~/.opencode/plan/`. Keep all planning documents
  inside the repository under `docs/spec/`. `PLAN.md` at the repo root links them.
- The canonical migration spec lives in `docs/spec/` (`00-overview.md`,
  `01-architecture.md`, `02-integration-verifier-compound.md`,
  `03-tasks-risks.md`, `04-adversarial-audit.md`). Treat
  `04-adversarial-audit.md` as normative when documents conflict.
